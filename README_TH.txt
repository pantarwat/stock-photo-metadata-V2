AI Stock Vision V2.4 — Single File

1) ติดตั้ง Python 3.11 หรือใหม่กว่า
2) เปิด Terminal ในโฟลเดอร์นี้
3) รัน: pip install -r requirements.txt
4) รัน: streamlit run app.py
5) ใส่ API Key ในช่อง Password หรือสร้าง .streamlit/secrets.toml

ตัวอย่าง secrets.toml:
OPENAI_API_KEY = "sk-..."

ห้ามส่งหรือ commit API Key
